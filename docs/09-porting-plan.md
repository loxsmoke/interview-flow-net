## Parity checklist (acceptance)

Data compatibility
- [ ] Original data folder loads unmodified; port's writes load in the original
- [ ] `.env` round-trips through both apps (comments preserved)
- [ ] Resume tagged output byte-matches original for fixture corpus
- [ ] .docx export semantically matches original's for fixture state
- [ ] Timestamps remain naive local ISO-8601

Rendering fidelity (must match)
- [ ] Heading sizes 24/20/17.6 px, weight 600, body `#cbd5e1`
- [ ] `breaks: true` — single newlines are line breaks
- [ ] GFM tables styled per spec; inline/fenced code styling
- [ ] Tag emojis decorated outside mermaid fences only
- [ ] Mermaid renders with all 5 normalizations; failure leaves code at 80 % opacity
- [ ] `search-warning` HTML block displays styled
- [ ] http/https links open OS browser; other schemes ignored; no in-pane navigation
- [ ] Text selectable in prose panes
- [ ] Tagged-resume preview metrics match §4.6

Behavior
- [ ] 12 steps + custom actions + About + Config all reachable; step locking, badges, progress bar
- [ ] Queue: single slot, fixed order, cancel/dequeue, button label state machine
- [ ] LiveTracePanel: prompts, streamed deltas with pinned auto-scroll, web activity, rate-limit countdown
- [ ] Cost badges (per-section + Debrief total with tooltip breakdown)
- [ ] All four providers stream; temperatures per section; pricing table applied
- [ ] Mock interview END_OF_INTERVIEW handling; Enter/Shift+Enter
- [ ] Resume Tailor splitter, diff, Use AI Resume extraction regex
- [ ] Migration wizard 5 phases with verify + safe failure
- [ ] Runs on Windows 11 and macOS (arm64 at minimum)

## Risk register

| Risk | Impact | Mitigation |
|---|---|---|
| Custom native renderer misses fidelity details (tables, breaks, spacing) | High — core requirement | M0 Markdig spike + golden-corpus screenshot gate on both OSes; §4.2 metrics are the contract |
| Mermaid-in-JS-engine infeasible (DOM dependence) | High for diagram parity | ADR-001b ordered fallbacks: JS engine + shim → pinned older mermaid → native MSAGL layout of the flowchart subset; revisit ADR-001 only if all fail |
| Streaming re-parse performance in native MarkdownView | Med | Throttle re-parse; incremental block-level reuse if profiling demands |
| PDF extraction differences (PdfPig vs PyMuPDF) | Med | Fixture corpus + tolerance rules; heuristic tuning |
| Provider SDK gaps (usage metadata, web-search tools, retry headers) | Med | Raw HttpClient fallback per provider |
| DOCX raw-dump annotation parity | Low | It's diagnostic display only — verify tolerance with user |
| Two apps writing one data file concurrently | Low | Same last-write-wins as original; document "don't run both at once" |
